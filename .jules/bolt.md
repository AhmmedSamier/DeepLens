## 2026-07-16 - Fast path fuzzy match using parallel arrays
**Learning:** Bitflags provide a very fast optimization strategy by pre-checking if the query characters exist in the searched property (like path, name or fullName) before executing expensive O(M*N) string matching algorithms like `Fuzzysort.single()`. Managing these bitflags as parallel `Uint32Array` buffers ensures O(1) checks during hot loops without allocating objects.
**Action:** Always maintain all lifecycle aspects (allocation, moving, shrinking, and freeing memory) of parallel arrays to ensure data consistency and prevent memory leaks. Use property-specific bitflag arrays (like `itemPathBitflags` alongside `itemNameBitflags`) rather than generic `itemBitflags` in property-specific checks because a general item match doesn't mean the specific property matches the bitmask.
