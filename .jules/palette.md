## 2024-07-24 - Search View Accessibility Focus Management
**Learning:** When creating custom search interfaces with arrow key navigation, focus often stays on the input field while a visual highlight moves through a separate list of results. Without explicit ARIA attributes, screen readers only announce the input text and fail to read out the currently highlighted search result.
**Action:** Use the ARIA Combobox pattern. Add `role="combobox"`, `aria-expanded`, and `aria-activedescendant` to the search input. Apply `role="listbox"` to the container and `role="option"` with dynamic `aria-selected` attributes and unique IDs to the list items to ensure screen readers correctly announce highlighted items during keyboard navigation.
