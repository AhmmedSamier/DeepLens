## 2024-08-18 - ARIA Combobox for Search Results
**Learning:** Custom command palettes and search views that use an `<input>` for searching and a separate `<div>` list for results are entirely inaccessible to screen readers without ARIA combobox patterns. Arrow key navigation visually updates selection, but the screen reader remains focused on the input and silent about the changes.
**Action:** Always apply the W3C ARIA Combobox pattern (`role="combobox"`, `aria-activedescendant`, `aria-expanded` on input, `role="listbox"` on container, and `role="option"` with IDs on items) when building custom search/autocomplete views to ensure screen readers announce highlighted results during keyboard navigation.
